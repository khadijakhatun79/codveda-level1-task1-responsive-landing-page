# TechWave — Responsive Podcast Landing Page

Codveda Technology Front-End Development Internship — Level 1 Task 1.

## Technologies
- Semantic HTML5
- CSS3 (Flexbox, Grid, media queries, keyframe animations)
- Vanilla JavaScript (mobile navigation and demo form feedback)

## Features
- Responsive layout for desktop, tablet and mobile
- Accessible navigation labels and semantic sections
- CSS mobile menu styling + JavaScript menu interaction
- Smooth scrolling and subtle CSS animations
- Podcast hero, About, Episodes, Host, Subscribe form and Footer
- Email validation and inline form confirmation (demo only)

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Note
The microphone illustration is an emoji/CSS composition, so the project works without external image assets.
The subscribe form is a frontend demo and does not store or send email addresses.
